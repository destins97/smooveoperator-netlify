# Design concepts

Five interactive direction studies for the next SmooveOperator site. Open `index.html` in a browser to browse them.

These files live outside `src/` and `public/`, so the Netlify build does not publish them. Every concept keeps the Yellowtail neon wordmark, Absolute Black `#000000` and Lamborghini Gold `#FFC000`. Figures inside the concepts are illustrative examples, not business data.

**Owner preference (2026-09-27): Direction 2, Night Route, is the favorite.** Use it as the lead direction for the production redesign.

| File | Direction |
| --- | --- |
| `atelier.html` | Generative art platform: AI art preview, style gallery, creator tools, minting flow |
| `night-route.html` | Cinematic light trails, spec strip, scroll route, partnership outline |
| `constellation.html` | Orbital map of supplier and partner relationships |
| `ledger.html` | Live buy decision instrument and example purchase order |
| `prep-showroom.html` | Rising sun hero, exploded 3D carton, prep specification sheet |
